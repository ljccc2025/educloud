# 直播观看页主题与聊天区布局优化设计

## 背景

学生端直播观看页当前将整个页面固定为深色背景，浅色系统下视觉突兀；右侧实时讨论区使用固定高度，在桌面小视口中底部输入区可能被裁切。此次优化只处理主题适配和现有聊天区布局，不新增业务功能、控件或文案。

## 已确认方案

采用 A「自适应页面外壳」：

- 页面外壳、面包屑、课程信息卡和实时讨论区使用 Tailwind 的系统主题 `dark:` 变体，跟随操作系统的 `prefers-color-scheme`。
- 视频播放器画布继续保持深色，确保直播观看时的聚焦感；播放器外的页面在浅色系统中保持浅色，在深色系统中切换为深色。
- 实时讨论区改为可收缩的纵向 flex 布局：消息列表占用剩余空间并滚动，底部输入区作为固定的非收缩区域始终完整显示。
- 桌面端聊天区高度使用动态视口单位，并扣除导航和页面内边距；设置合理的最小高度，避免大屏或窄高视口出现异常。移动端继续使用现有的自然流式高度。
- 不改变现有路由、接口、消息数据、播放器交互和导航信息架构。

## 代码落点

- `educloud-frontend/student-portal/src/pages/LiveRoom.tsx`
  - 将页面根容器从固定 `bg-ink-900` 改为浅色默认和 `dark:` 深色变体。
  - 调整桌面端内容网格及聊天区高度约束，确保输入区位于可视区域内。
- `educloud-frontend/student-portal/src/components/ChatBox.tsx`
  - 为聊天容器、标题、消息气泡、输入区补充系统主题变体。
  - 为可滚动消息列表补充 `min-h-0`，防止 flex 子项撑破容器。
- 如有必要，`educloud-frontend/student-portal/src/index.css`
  - 仅补充直播页高度所需的局部样式；不修改全局排版或其他页面视觉。

## 验收标准

1. 在 Playwright 中以浅色系统打开 `/live/1`：页面外壳、课程信息和聊天区为浅色，播放器仍为深色。
2. 在 Playwright 中以深色系统打开 `/live/1`：页面外壳、课程信息和聊天区切换为深色，页面无固定浅色块造成的突兀对比。
3. 桌面视口下聊天区底部输入框完全位于可视区域内；消息列表可独立滚动，不遮挡输入框。
4. 移动视口下页面不出现横向溢出，现有直播信息和聊天输入功能仍可用。
5. 学生端 TypeScript/Vite 编译通过，相关 Playwright 验证通过。
6. 不引入主题切换按钮、额外业务字段、额外装饰或未请求的交互。

## 验证计划

- 先用 Playwright 复现当前浅色/深色和小视口下的布局尺寸，记录聊天面板与输入区的实际边界。
- 先补充针对主题和布局的最小失败断言，再实现样式修复。
- 使用 Playwright 在浅色、深色及移动视口回归，检查 computed style、元素边界、滚动容器和控制台错误。
- 执行学生端构建，并运行 `git diff --check`；最终进行中文代码 review。

## 非目标

- 不重做视频播放器、不接入真实直播流、不修改聊天业务逻辑。
- 不调整订单、课程分类、作业考试等已完成的其他页面。
- 不复制 51CTO 的具体视觉资产；仅参考其课程观看页的分区和观看聚焦原则。
