# 首页课程分类深链与编号布局设计

## 目标

让首页十张课程分类卡片进入课程中心时自动选中同名分类，并修复分类区装饰编号 `02` 与说明文字重叠的问题。

## 方案比较

### 方案 A：URL 查询参数（采用）

- 首页生成 `/courses?category=<分类名>`，课程中心以 `category` 参数作为分类筛选的唯一来源。
- 课程中心点击分类或“全部分类”时同步更新 URL，刷新、分享和浏览器前进后退都能保持筛选状态。
- 与现有页脚分类链接格式一致，不增加新路由或全局状态。

### 方案 B：React Router location state

- 不污染 URL，但刷新后丢失分类状态，也无法复制链接分享，故不采用。

### 方案 C：全局 store

- 可跨页保存筛选，但会让 URL 与界面状态脱节，并扩大本次改动范围，故不采用。

## 行为设计

- 首页每张分类卡片使用 `encodeURIComponent(cat.name)` 生成查询参数。
- 课程中心只接受 `categories` 中存在的分类名；缺失或无效参数回退到“全部分类”。
- 课程中心侧栏选中分类时保留其他查询参数，只更新 `category`；选择“全部分类”或清除筛选时删除 `category`。
- 课程过滤逻辑继续使用现有本地课程数据，不修改接口或课程卡片。

## 编号布局

- `02` 保持纯装饰并继续使用 `aria-hidden="true"`。
- 移除相对于整个标题区的绝对定位，将编号放进右侧说明列的正常文档流，位于说明文字上方并右对齐。
- 窄屏自然堆叠；桌面与移动端都不能和说明文字发生边界相交，也不能产生横向溢出。

## 文件边界

- 修改 `educloud-frontend/student-portal/src/pages/Home.tsx`：分类深链和编号布局。
- 修改 `educloud-frontend/student-portal/src/pages/CourseList.tsx`：读取、验证并同步 `category` 查询参数。
- 不修改分类数据、课程接口、其他筛选业务、Navbar、Footer 或首页其他模块。
- 不新增依赖，不清理或提交工作区其他已有改动；生产代码保持未提交、可逆。

## 验收标准

- 点击“计算机”后 URL 为 `/courses?category=计算机`（浏览器可编码显示），课程中心高亮“计算机”，列表只展示计算机课程。
- 点击“数学”等其余分类得到同名筛选；无效分类回退到全部课程。
- 课程中心侧栏切换分类会同步 URL；“全部分类”和“清除全部筛选”会移除 `category`。
- 桌面端和 390px 移动端中，`02` 与说明文字边界不重叠，页面无横向溢出。
- `npm run typecheck`、`npm run build`、浏览器验收和限定路径 `git diff --check` 通过。
