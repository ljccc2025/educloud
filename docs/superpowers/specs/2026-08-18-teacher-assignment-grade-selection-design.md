# 教师端作业批改选择状态设计

## 背景

教师在“作业批改”页面切换作业后，`GradeSheet` 仍保留上一份作业的学生提交 ID。该 ID 不属于新作业时，右侧详情会先退化为空状态，教师必须再次点击学生；空状态与完整详情的高度和内容差异也造成明显的界面瞬移。

## 已确认行为

- 每份作业分别记住老师最后查看或批改的学生。
- 再次进入该作业时，恢复该学生详情。
- 首次进入作业时，默认显示提交列表第一位学生。
- 已记录的学生不再存在时，回退到第一位学生。
- 记忆范围仅限当前“作业批改”页面会话；不增加本地存储或后端字段。

## 状态边界

`AssignmentGrade` 持有 `assignmentId -> submissionId` 映射，并根据当前作业计算有效的学生 ID。`GradeSheet` 不再自行初始化学生选择，只接收当前学生 ID 和选择回调。这样切换作业时传入的 ID 始终属于当前作业，右侧详情不会短暂进入空状态。

## 修改范围

- 修改 `AssignmentGrade.tsx`：维护每份作业的最后选择，并传递受控属性。
- 修改 `GradeSheet.tsx`：移除内部学生选择状态，使用父组件提供的选择值和回调。
- 不修改 API、作业数据结构、评分提交逻辑和现有视觉样式。

## 验证

- Playwright 验证首次进入每份作业都会直接显示学生详情。
- Playwright 验证分别选择两份作业中的不同学生后，往返切换可恢复各自选择。
- Playwright 验证切换作业后右侧不出现“请从左侧选择一份提交进行批改”的中间空状态。
- 运行 TypeScript 检查与 Vite 生产构建。
