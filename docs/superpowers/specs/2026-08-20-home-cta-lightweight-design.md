# 首页暖白轻量 CTA 设计

## 目标

将学生端首页底部“准备好开始学习了吗？”行动引导区从大面积深靛蓝横幅调整为暖白、低饱和、编辑式 CTA，使它自然承接浅色课程分类区，同时保留清晰的课程入口和必要的视觉强调。

本次只调整 CTA 的视觉层级、响应式布局和轻量交互，不改变标题、说明文字、按钮文案、`/courses` 路由或首页其他模块。

## 当前问题

- CTA 是首页尾部唯一的大面积深靛蓝色块，与纸张背景和浅色分类卡片形成突兀断层。
- 深色背景、白色大标题、橙色按钮、网格纹理和巨大箭头同时争夺注意力，视觉重量超过其页面收尾职责。
- `p-12 md:p-16` 与大面积背景组合使横幅显得偏高，更像独立广告位而非首页内容的自然延续。
- CTA 与页面品牌色保持一致，但靛蓝和琥珀都以高强度大面积出现，缺少主次。

## 设计方案

### 1. 容器与背景

- 保留现有 `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8` 页面宽度和圆角卡片轮廓。
- 背景改为暖米白到极浅靛蓝的低饱和渐变，综合色值接近 `amber-50`、白色和 `indigo-50`。
- 增加一条低对比度暖色细边框和极轻阴影，使 CTA 在纸张背景中有明确归属，但不形成新的重色块。
- 删除 30px 网格纹理和右下角巨大 `>` 装饰，改用不影响可读性的柔和径向光晕或纯 CSS 低透明度色斑。
- 容器内边距收紧为约 `p-8 md:p-10 lg:p-12`，保持呼吸感同时减少广告横幅感。

### 2. 信息层级与布局

- 桌面端使用左右双列：左侧为标题和说明，右侧为主按钮；两侧垂直居中。
- 标题使用现有 `font-display` 与深墨色 `text-ink-900`，字号保持 `text-3xl md:text-4xl`。
- 说明文字使用 `text-ink-500`，最大宽度约 42rem，避免一行过长。
- 主按钮保持“立即开始”和右箭头，使用品牌靛蓝作为主背景；琥珀色只用于小面积 hover/focus 强调。
- 不增加第二按钮、插图、统计数字、促销徽章或新的信息层级。

### 3. 响应式行为

- 桌面端内容与按钮横向排列，按钮保持不收缩并位于右侧。
- 768px 以下改为纵向排列，按钮左对齐并保持至少 44px 的触摸高度。
- 390px 宽度下标题和说明自然换行，容器不得产生横向溢出或按钮截断。
- CTA 与上方分类区、下方页脚继续使用原有页面间距，不调整其他模块的位置和结构。

### 4. 交互与可访问性

- 整体容器不设为可点击，仅“立即开始”链接作为交互目标，继续跳转 `/courses`。
- 按钮保留清晰的键盘 focus ring，文字与背景达到 WCAG AA 对比度。
- hover 只允许轻微颜色、阴影和箭头位移，持续约 200–250ms。
- `prefers-reduced-motion: reduce` 下取消箭头位移和过渡动画，功能与 focus 状态不受影响。
- 背景光晕和色斑使用 `aria-hidden` 或纯 CSS 表现，不进入辅助技术阅读顺序。

## 文案与业务边界

- 保留标题“准备好开始学习了吗？”、当前说明文字和按钮“立即开始”。
- 本次不判断或实现“首单立减 50 元”的促销业务；如后续确认该活动不存在，应作为独立内容需求修改，避免视觉任务扩大为营销逻辑变更。
- 保留 `/courses` 跳转，不新增埋点、登录判断、个性化推荐或后端接口。

## 实现边界

- 预计只修改 `educloud-frontend/student-portal/src/pages/Home.tsx` 的 CTA 区域。
- 优先复用现有 Tailwind 色阶和按钮设计语言，不修改全局颜色令牌，不新增依赖或图片资源。
- 不修改课程分类区、Footer、Navbar、SideRays、课程筛选逻辑及工作区其他已有差异。
- 生产改动保持小而可逆，并在用户确认实现前保持未提交。

## 验收标准

- 1440px 桌面端 CTA 使用低饱和暖白渐变，不再出现深靛蓝大色块、网格纹理或巨大箭头。
- 桌面端文案与按钮形成清晰双列；390px 移动端自动堆叠，无横向溢出。
- 标题、说明、按钮文案和 `/courses` 路由保持不变。
- 按钮 hover、键盘 focus 和 reduced-motion 状态符合设计要求。
- CTA 与上方浅色分类区自然衔接，页面其他模块的结构和行为保持不变。
- `npm run typecheck`、`npm run build`、浏览器桌面/移动端验收和限定路径 `git diff --check` 通过。
