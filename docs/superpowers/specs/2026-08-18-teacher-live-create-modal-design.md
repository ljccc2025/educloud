# 教师端创建直播弹窗设计

## 背景

教师端“直播管理”页面打开“创建直播”后，当前遮罩只覆盖页面内容区域，未覆盖顶部栏和侧边栏；背景仍可滚动；弹窗受页面滚动位置影响，底部表单和操作按钮会落到视口外。

根因是弹窗节点位于带 `animate-fade-up` 的页面容器内部。该动画保留 `transform`，使后代的 `position: fixed` 以该容器而非浏览器视口作为包含块。

## 已确认目标

- 采用方案 B：暖色液态玻璃。
- 遮罩固定覆盖整个浏览器视口，包括顶部栏、侧边栏和主内容区域。
- 弹窗打开时锁定背景页面滚动，关闭或卸载时恢复原状态。
- 常见桌面视口一次完整展示标题、课程、开播时间、简介与操作按钮。
- 低高度或小屏视口允许弹窗内部滚动，但背景始终保持锁定。
- 保留现有创建直播字段、校验、提交与取消逻辑，不增加新的业务选项。

## 方案

### 渲染边界

使用 React `createPortal` 将弹窗渲染到 `document.body`，使全屏定位不再受页面动画 `transform` 影响。遮罩使用高于教师端顶部栏的层级，并以 `fixed inset-0` 覆盖视口。

### 液态模糊视觉

遮罩由三层组成：

1. 半透明深色底层，维持表单与背景的可读对比。
2. `backdrop-blur` 与适度饱和度增强，形成全视口磨砂效果。
3. 暖琥珀与浅靛蓝的模糊径向光晕，形成方案 B 的液态质感。

表单容器采用半透明浅色玻璃、细白色边框、柔和阴影和适度圆角，保持教师端现有浅色视觉体系。

### 尺寸与滚动

- 遮罩负责视口级居中和外部留白。
- 弹窗设置现有 `max-w-lg` 宽度，并限制 `max-height` 为视口高度减去安全边距。
- 桌面端收敛表单纵向间距，使常见视口下全部字段一次显示。
- 内容超过限制时，仅弹窗容器启用 `overflow-y-auto`。
- 不允许滚动事件带动弹窗背后的页面。

### 背景滚动锁定

当 `showCreate` 为 `true` 时保存 `document.body.style.overflow` 的旧值并设置为 `hidden`；弹窗关闭或组件卸载时恢复旧值，避免影响其他页面。

## 交互保持

- “创建直播”按钮仍打开弹窗。
- “取消”仍关闭弹窗。
- 创建成功后仍关闭弹窗并清空表单。
- 标题为空或未选择课程时仍保持当前不提交行为。
- 不修改直播列表、筛选标签、直播开始或结束逻辑。

## 验收标准

1. 打开弹窗后，遮罩几何边界与浏览器视口一致。
2. 顶部栏、侧边栏和内容区均位于液态模糊遮罩下。
3. 弹窗打开期间，背景滚动位置保持不变，`body` 禁止滚动。
4. 关闭弹窗后恢复原滚动能力和原滚动位置。
5. 典型桌面视口中，弹窗标题、全部四个字段和两枚操作按钮均在视口内。
6. 低高度与移动视口中没有页面横向溢出；弹窗内部可滚动到全部字段与按钮。
7. 原有创建和取消行为保持可用，页面无控制台错误。
8. 教师端生产构建通过。

## 验证策略

- Playwright 修复前回归：确认遮罩未覆盖完整视口、背景可滚动或按钮超出视口。
- Playwright 修复后桌面验证：检查遮罩边界、背景锁定、字段与按钮可见性。
- Playwright 低高度和移动视口验证：检查无横向溢出、背景锁定与弹窗内部滚动。
- 运行教师端 `pnpm build` 与 `git diff --check`。
- 使用中文代码审查检查正确性、兼容性、性能和变更范围。
