# 设计规格说明：学生端课程学习页（Learning.tsx）居中重构

## 1. 目标与背景
修复当前学生端课程学习页面（`/learn/:courseId`）在宽屏下播放器贴边、黑色背景过宽拉伸、右侧目录孤立且无真实章节数据的问题。重构为**经典居中双栏卡片模式**（Coursera / Udemy 风格），提升视听学习体验与多端一致性。

---

## 2. 页面布局与视觉架构

### 2.1 整体版心布局
- **外层容器**：全局采用 `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 py-6` 居中约束（最大宽度 1280px），消除贴边与不对称黑框。
- **页面背景**：柔和灰底 `bg-ink-50/40`，突出卡片立体层级。
- **顶部面包屑与导航**：
  - 左侧：课程名、所属分类、当前播放课件名称。
  - 右侧：返回课程主页、我的课程快捷入口。

### 2.2 左侧主体区（`lg:col-span-8` 或 `flex-1 min-w-0`）
1. **视频播放卡片**：
   - 采用 `aspect-video w-full rounded-2xl overflow-hidden shadow-md bg-ink-950`，严格保持 16:9 比例。
   - 嵌入 `VideoPlayer` 组件，支持视频播放、暂停、全屏、音量与播放进度回调。
2. **课件操作与控制栏**：
   - 当前课件大标题、时长、类型标签（`VIDEO` / `DOCUMENT` / `EXTERNAL`）、免费试看标签。
   - 学习控制：`[◀ 上一节]`、`[标记已完成 / 下一节 ▶]` 动作联动。
3. **课程详情与资料 Tabs**：
   - Tab 1: **课程介绍与讲师**（课程描述、学习目标、讲师头像与简介）。
   - Tab 2: **配套资料**（文档课件、PDF 讲义在线预览/下载入口）。
   - Tab 3: **常见问题**。

### 2.3 右侧目录与进度区（`lg:w-96` 或 `lg:col-span-4`）
1. **课程进度卡片**：
   - 环形或条形进度条（`user_course_progress`），显示已学课时数 / 总课时数与百分比。
2. **章节课件可折叠目录（Accordion Tree）**：
   - 数据源对接：调用 `GET /api/v1/courses/:courseId/chapters` 实时渲染真实章节列表。
   - 课件列表项状态：
     - **正在播放**（高亮背景 + 播放中动态图标）。
     - **已完成**（绿色勾选图标）。
     - **未学习 / 锁定**（区分试看与购课锁）。
   - 点击课件项即时切换主播放器内容，并同步上报学习心跳。

---

## 3. 异常与边界处理
- **加载中状态**：骨架屏（Skeleton）占位，避免页面闪烁。
- **课程不存在 / 404**：居中空状态卡片，带“返回课程广场”引导。
- **无章节内容 / 草稿态**：友好提示“讲师正在紧锣密鼓准备内容，敬请期待”。
- **移动端响应式适配**：`lg:` 断点下为双栏并排；移动端为单栏上下堆叠，目录支持底部抽屉折叠。

---

## 4. 交付与验证计划
1. 本地更新 `student-portal` 的 `Learning.tsx` 及关联 API 数据获取。
2. 运行 `tsc && vite build` 确保类型检查与打包通过。
3. 同步至 VM 并在浏览器中通过 `chrome-devtools` 验证 1080P、宽屏各分辨率下的居中效果与交互流畅度。
