# 教师端创建考试弹窗设计

## 背景

教师端“考试管理”页面的“创建考试”弹窗目前使用普通白色面板和深色遮罩，与已经确认的“创建直播”液态玻璃弹窗风格不一致；弹窗仍位于带页面入场动画的内容容器内，也存在全视口定位和低高度屏幕展示不稳定的风险。

## 已确认目标

- 采用视觉原型方案 A：与“创建直播”完全统一的紧凑液态玻璃弹窗。
- 遮罩固定覆盖浏览器完整视口，包括顶部栏、侧边栏和主内容。
- 弹窗打开时锁定背景滚动，关闭或卸载时恢复原状态。
- 桌面端尽量完整展示所有字段和操作按钮；低高度或小屏仅允许弹窗内部滚动。
- 保留考试标题、关联课程、题目数量、时长、开考时间以及现有创建、取消和校验逻辑。
- 不新增考试业务字段，不调整考试列表、统计卡片和操作行为。

## 设计方案

### 渲染边界

使用 React `createPortal` 将弹窗挂载到 `document.body`，避免页面根容器的 `animate-fade-up` 变换影响 `fixed` 定位。遮罩使用 `fixed inset-0` 和高于教师端导航的层级，确保覆盖整个浏览器视口。

### 视觉一致性

直接复用“创建直播”弹窗的视觉语言：

1. 半透明靛蓝底层与全视口 `backdrop-blur`。
2. 暖琥珀和浅靛蓝模糊光晕，形成液态背景层。
3. 半透明白色玻璃面板、细白边框、柔和阴影和一致圆角。
4. 保持 `max-w-lg` 紧凑宽度，数字字段继续采用两列布局。

### 尺寸与滚动

- 外层遮罩负责视口级居中、安全留白和背景裁切。
- 弹窗最大高度为动态视口高度减安全边距，内容超过上限时只滚动弹窗。
- 弹窗使用 `overscroll-contain`，避免滚动链传递给背景页面。
- 小屏下表单保持单列主字段，题目数量和时长仍在可用宽度内并排；不产生横向溢出。

### 背景滚动锁定

`showCreate` 为 `true` 时保存 `document.body.style.overflow` 并设为 `hidden`；弹窗关闭或组件卸载时恢复旧值，避免影响其他教师端页面。

### 可访问性

弹窗容器提供 `role="dialog"`、`aria-modal="true"` 和标题关联；原生表单控件与标签关系保持不变。

## 交互保持

- “创建考试”按钮仍打开弹窗。
- “取消”仍关闭弹窗。
- 创建成功后仍关闭弹窗并重置当前表单。
- 原有必填判断、数值转换和考试数据创建逻辑不变。
- 不添加用户未要求的字段、提示步骤或业务细节。

## 验收标准

1. 弹窗遮罩边界与浏览器视口完全一致。
2. 顶部栏、侧边栏和主内容均位于液态模糊遮罩下。
3. 弹窗打开时 `body` 禁止滚动，关闭后恢复打开前的滚动状态。
4. 常见桌面视口内可以看到全部字段和创建、取消按钮。
5. 低高度与移动视口不产生横向溢出，且可在弹窗内部滚动到所有内容。
6. 创建和取消交互、原有字段校验与列表更新逻辑保持正常。
7. 页面无新增控制台错误，教师端生产构建通过。

## 验证策略

- 使用 Playwright 验证桌面和低高度视口的遮罩边界、滚动锁定、弹窗可见范围及关闭后恢复。
- 验证标题为空或课程未选择时不创建，合法数据仍能完成创建并关闭弹窗。
- 运行教师端 TypeScript 检查、生产构建和 `git diff --check`。
- 最终对变更范围、交互兼容性和响应式布局进行代码审查。
