# 顶部导航栏滚动过渡设计

## 目标

修复学生端顶部药丸导航栏在页面滚动时宽度和圆角瞬间变化的问题，使导航从居中药丸平滑过渡到贴边导航，并在回到顶部时平滑反向收缩。

## 根因

当前 `Navbar.tsx` 使用 Tailwind 状态类在两个不可连续插值的 CSS 值之间切换：

- `max-width: 1280px` 切换到 `max-width: none`，浏览器只能离散切换宽度约束。
- `border-radius: 9999px` 切换到 `0`。虽然数值理论上可插值，但起始值远大于实际药丸半径，动画绝大部分时间视觉上仍保持药丸，末尾才快速变直角。

## 设计方案

导航栏保留现有滚动监听、`requestAnimationFrame` 节流和滚动态高度，仅调整可视容器的过渡属性：

1. 外层 header 的横向/顶部 padding 继续从顶部药丸状态过渡到滚动态贴边状态。
2. 内层导航表面始终保持 `mx-auto`，使用显式数值 `max-width: 1280px → 100vw`，让宽度约束可插值。
3. 使用实际药丸几何半径 `28px → 0`，让左右圆角在整个动画周期内连续收束。
4. 以显式 transition 列表统一过渡 `max-width`、`border-radius`、`height`、`background-color`、`box-shadow` 和 padding 相关属性，动画时长为 520ms，曲线为 `cubic-bezier(0.4, 0, 0.2, 1)`。
5. 保持滚动后的最终状态为全宽、0 圆角，符合现有信息架构；移动端沿用同一状态机。
6. 对 `prefers-reduced-motion: reduce` 保留即时切换，不强制播放动画。

## 验收标准

- 滚动开始后 100ms、300ms、500ms 的导航宽度单调增加，不能出现从 1280px 直接跳到全宽的离散变化。
- 同一时间点圆角单调从 28px 收束到 0，不能出现 9999px 长时间保持后末尾瞬移。
- 动画结束时导航左右贴齐视口，宽度为视口宽度，圆角为 0；回到顶部后恢复药丸状态。
- 桌面端和 390px 移动端无横向溢出；移动端菜单仍可打开和点击导航项。
- 控制台无新增错误，类型检查和生产构建通过。
