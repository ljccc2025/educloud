# 首页课程分类轻量化设计

## 目标

将学生端首页的“课程分类 / 探索你的方向”模块从突兀的深色大卡片，调整为与首页纸张背景、精选课程和后续 CTA 更自然衔接的轻量分类导航。

本次只调整视觉层级、响应式布局和分类入口的可识别性，不改变首页信息架构、课程分类数据来源、路由结构或其他首页模块。

## 当前问题

- 深靛蓝大容器是首页中唯一的大面积深色块，与上下浅色内容区割裂。
- 深色容器内部再叠加半透明小卡片，形成过重的双层容器关系。
- 10 个分类采用六列布局，桌面端形成“6 + 4”的不平衡第二行。
- `categoryIcons[cat.name] ?? '+'` 对当前分类名称覆盖不足，多个分类退化为 `+` 占位符，削弱了入口的语义和完成度。

## 设计方案

### 1. 容器与页面节奏

- 移除分类区内部的 `bg-indigo-800`、深色网格纹理和大圆角容器。
- 分类区恢复使用页面纸张背景，与上下模块共享同一内容流。
- 保留 `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8` 的页面宽度约束和原有上下节奏。
- 分类区使用轻微的上下边界或留白建立章节分隔，不添加新的全宽深色背景。
- 可保留一个极低对比度的章节编号 `02` 作为装饰，但不得影响文字对比度或点击区域。

### 2. 标题层级

- 保留“课程分类”和“探索你的方向”文案。
- 标题改为与“热门推荐”一致的左对齐编辑式层级：琥珀色小标签、衬线大标题。
- 标题右侧增加一段不超过两行的辅助说明，解释分类区的用途，不引入新的业务承诺。
- 桌面端标题与说明采用双列对齐；窄屏自动堆叠。

### 3. 分类网格

- 桌面端使用 5 列，10 个分类形成平衡的 `5 + 5` 两行布局。
- 中等屏幕使用 3 列，移动端使用 2 列，保持卡片最小可读宽度。
- 每个分类卡片采用 `min-height`、浅色背景、细边框和小幅阴影，不使用深色填充。
- 卡片信息顺序为：语义图标、分类名称、课程数量；右上角可以放置轻量箭头提示可进入。
- Hover/focus 状态只改变边框、图标底色、阴影和轻微位移，过渡时间约 200–250ms。
- 保持现有分类入口的点击行为；本次不新增筛选状态或修改后端数据。

### 4. 图标与色彩

- 为当前十个分类提供稳定的语义图标映射：计算机、数学、语言学习、经济管理、文学艺术、设计、心理学、法律、音乐、哲学。
- 图标使用现有前端图标体系或同等风格的线性图标，不再使用 `+` 作为缺省视觉。
- 主文字沿用 `ink` 色系，图标底座使用浅靛蓝和浅琥珀交替强调；琥珀只作为交互强调色。
- 文字与背景需满足 WCAG AA 对比度；分类数量不能只依靠颜色表达。

## 响应式与可访问性

- 所有分类入口继续使用语义化链接，并保留可见的键盘 focus 状态。
- 触摸端卡片点击区域不小于 44px 高度，避免只把箭头设为可点击。
- `prefers-reduced-motion: reduce` 下取消位移和颜色过渡，仅保留状态切换。
- 390px 宽度下不得出现横向溢出；标题、说明和卡片内容允许自然换行。
- 分类名称和课程数量保持真实文本，不能仅使用图标或装饰字符。

## 实现边界

- 预计修改：`educloud-frontend/student-portal/src/pages/Home.tsx`，必要时新增一个仅负责图标映射的本地常量或小型展示组件。
- 不修改：课程分类数据接口、课程列表筛选逻辑、Navbar、精选课程、统计区和 CTA 的业务行为。
- 不新增依赖，不删除现有 Galaxy/SideRays 源文件，不清理工作区其他未提交改动。
- 保持改动小而可逆；生产代码在用户审阅规格后再进入实施计划。

## 验收标准

- 桌面端 1440px 下分类卡片呈 5×2 平衡网格，页面无横向溢出。
- 移动端 390px 下呈 2 列网格，标题和说明不被截断，卡片可点击。
- 页面截图中分类区不再出现突兀的深色大卡片和 `+` 占位图标。
- Hover、键盘 focus 和 reduced-motion 状态符合设计边界。
- `npm run typecheck`、`npm run build` 和 `git diff --check` 通过。
- 现有首页其他模块、路由和课程数据行为保持不变。
