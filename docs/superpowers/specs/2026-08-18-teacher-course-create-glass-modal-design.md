# 教师端新建课程液态玻璃弹层设计

> 日期：2026-08-18
>
> 状态：已确认设计
>
> 范围：教师端课程管理页的“新建课程”入口

## 1. 背景

教师端课程管理页当前点击“新建课程”后跳转到 `/courses/edit/new`，在独立页面展示完整课程表单。教师端“创建考试”和“创建直播”已经采用液态玻璃弹层：原页面保留为上下文，覆盖深靛色柔化背景、琥珀与靛蓝光晕，以及半透明玻璃面板。

本次将新建课程入口统一为同一视觉语言，同时保留现有课程创建数据结构、Store 方法与创建后的编辑流程。

## 2. 目标与非目标

### 2.1 目标

- 点击课程管理页“新建课程”后，在当前列表上方打开液态玻璃弹层。
- 复用现有 `CourseForm` 和 `useCourseStore.createCourse`，不复制字段与保存逻辑。
- 保存成功后进入已创建课程编辑页，继续管理章节和封面。
- 取消后关闭弹层，保留列表搜索、状态筛选和滚动上下文。
- 与创建考试、创建直播的遮罩、光晕、玻璃材质和按钮风格保持一致。

### 2.2 非目标

- 不重构已有课程编辑页。
- 不修改课程类型、Mock API、Store 数据结构或后端契约。
- 不改动考试、直播和其他教师端页面。
- 不引入新的 UI、状态管理或测试框架。

## 3. 组件设计

### 3.1 `CourseManage`

- 用本地 `showCreate` 状态控制弹层。
- “新建课程”按钮改为打开弹层，不再直接导航到新建路由。
- 将 `createCourse` 传给弹层；创建成功后导航到 `/courses/edit/{createdId}`。
- 弹层关闭时不清空列表的搜索与筛选状态。

### 3.2 `CourseCreateModal`

新增独立组件，职责仅包括：

- 通过 Portal 渲染到 `document.body`，避免受页面层叠上下文影响。
- 渲染固定全屏遮罩、背景光晕与可滚动玻璃面板。
- 提供 Dialog 语义、标题关联和关闭入口。
- 打开期间锁定 `body` 滚动，关闭或卸载时恢复原值。
- 支持 `Escape` 和“取消”关闭；保存过程中禁止重复关闭和重复提交。
- 调用传入的异步创建方法；失败时保留表单与弹层，并在表单上方显示可重试的简短错误提示，不伪装成功。
- 打开时记录原焦点，关闭后将焦点还给“新建课程”按钮；Tab 键焦点保持在 Dialog 内。

### 3.3 `CourseForm`

继续作为课程字段和提交数据的唯一实现。新增最小展示接口：

- `onCancel?: () => void`：弹层模式下关闭表单。
- `variant?: 'page' | 'modal'`：只调整间距、封面区域高度和按钮布局，不改变字段含义。
- 默认值保持 `page`，确保已有课程编辑页视觉与行为不受影响。

## 4. 视觉规格

弹层沿用现有教师端玻璃弹层参数：

- 遮罩：`bg-indigo-950/25 backdrop-blur-xl`。
- 光晕：左侧琥珀色、右侧靛蓝色的大尺寸模糊圆形，仅作装饰且不响应指针。
- 面板：白色半透明背景、白色高光边框、`backdrop-blur-2xl`、`rounded-2xl` 和深靛色柔和阴影。
- 尺寸：桌面端最大宽度约 `3xl`，移动端保留安全边距；最大高度限制在视口内并允许面板内部滚动。
- 表单：标题和简介占整行，分类与定价在中等屏幕以上双列，封面区域采用紧凑高度。
- 操作：主按钮“保存课程”，次按钮“取消”；保存中显示明确状态并禁用重复提交。

## 5. 交互与数据流

```text
点击新建课程
  → CourseManage 打开 CourseCreateModal
  → CourseForm 收集并校验字段
  → useCourseStore.createCourse(data)
  ├─ 成功：关闭弹层 → 导航到 /courses/edit/{createdId}
  └─ 失败：保留弹层和输入内容 → 允许用户重试或取消
```

取消、按 Escape 或显式关闭只改变弹层状态，不调用创建 API。为避免误操作，不通过点击玻璃面板内部关闭弹层。

## 6. 可访问性与响应式

- 容器使用 `role="dialog"`、`aria-modal="true"` 和 `aria-labelledby`。
- 关闭按钮提供可读标签，键盘可聚焦。
- 首个课程标题输入框获得自动焦点，Tab/Shift+Tab 不会离开弹层，关闭后焦点回到触发按钮。
- 移动端表单改为单列，面板使用视口内滚动，操作按钮保持可触达。
- 装饰光晕使用 `aria-hidden` 或无语义元素，不进入阅读顺序。

## 7. 验证策略

教师端当前没有自动化测试脚本，本次不新增测试依赖。验证包括：

1. `npm run typecheck`。
2. `npm run build`。
3. 浏览器验证新建按钮、取消、Escape、滚动锁定、保存中状态和创建后跳转。
4. 检查桌面与窄屏下弹层不溢出视口。
5. 对比创建考试、创建直播，确认遮罩、光晕与玻璃面板视觉一致。
6. `git diff --check`，并确认只修改本设计列出的文件。

## 9. 验收标准

- 课程管理页点击“新建课程”时不离开列表，出现方案 A 的液态玻璃弹层。
- 弹层视觉与现有考试/直播创建弹层一致。
- 取消后课程列表的搜索、筛选与滚动上下文不变。
- 保存只执行一次，成功后进入新课程编辑页。
- 创建失败不会关闭弹层或丢失已填写内容。
- 已有课程编辑、章节管理和封面设置不发生回归。
