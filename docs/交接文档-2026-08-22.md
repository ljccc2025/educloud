## 5. 前端认证联调 + 注册/限流（最新完成）

### 5.1 认证联调（三门户）
- 每门户新增 `src/services/http.ts`：axios 实例（baseURL=/api/v1、withCredentials）、Bearer 注入、401 自动用 HttpOnly refresh_token Cookie 刷新并重放、后端错误码中文映射（apiErrorText）
- `api.ts`：login/me/logout（student 另有 register）改真实调用，返回形状与原 store 兼容
- `useAuthStore`：真实登录/登出/restore()（刷新页面自动恢复会话）
- `vite.config.ts`：/api 代理（`VITE_GATEWAY_TARGET` 环境变量，默认 http://127.0.0.1:8080）

### 5.2 学生注册（本轮新增）
- 登录页「登录|注册」双 Tab（UI 完全复用现有样式体系，品牌区零改动）
- 字段：用户名/邮箱/手机号/密码/确认密码/昵称（可选），与后端 RegisterStudentRequest 一致
- 流程：注册成功 → 回登录 Tab + 绿条提示 + 自动填用户名 → 手动输密码登录
- 前端校验用 JS 正则（**不要用 HTML pattern 属性**，见坑 4）

### 5.3 注册限流（本轮新增，后端）
- `RegistrationRateLimitFilter`（educloud-user）：POST /api/v1/auth/register 按 IP（5 次/5 分钟）+ 设备（X-Device-Id 头，3 次/5 分钟）双层 Redis 计数
- 超限 429 + Retry-After + code=RATE_LIMITED（复用 CommonErrorCode）；Redis 异常失败关闭 503（DEPENDENCY_UNAVAILABLE）
- 配置：educloud.user.registration.rate-limit.*（env 可覆盖）
- 注册方式：同文件嵌套 @Configuration + @Bean（**不用 @Component**，避免 @WebMvcTest 切片加载 Redis 依赖失败）
- 测试：RegistrationRateLimitFilterTest 6/6、RegistrationRateLimitIT 2/2（真实 Redis Testcontainer，VM 实测）

## 8. 关键坑与经验（下一位务必看）

1. **前端以 E 盘为准**：用户真实前端在 E:\VibeCoding数据集\再来一个微服务\educloud-frontend；git 仓库里的前端是 E 盘快照 + 联调改造。改前端先确认改动对象！
2. **crypto.randomUUID 只在安全上下文（https/localhost）可用**：局域网 http 访问会崩，必须用回退生成器（http.ts randomUuid，已修）。**排查浏览器"请求失败"先看这个**。
3. **HTML pattern 属性 + React = v 模式正则**：字符类里的连字符不允许字面位置（首尾也不行），任何写法都报 Invalid character in character class。**用 JS 正则校验代替 pattern**。
4. **kid 一致性**：JwtKeyProvider 与 generate-user-jwt-keys.sh 都必须对 modulus 无符号字节做 SHA-256（曾导致 Gateway 401）。
5. **@Transactional Bean 不能 final**（CGLIB）；测试同名 mock 会掩盖，真实启动才暴露。
6. **MySQL 保留字**：last_value 需反引号；GRANT 需 migration 账号有 GRANT OPTION（init 脚本已加）。
7. **RabbitMQ vhost**：spring.rabbitmq.virtual-host（不是 vhost）与 compose 对齐。
8. **直连无 X-Request-Id 时审计列报错**：统一用 RequestIds.from(request)。
9. **Gateway AccessPolicy**：匿名放行清单要包含新 auth 端点（logout 已加）。
10. **vite proxy 的 target 用 VITE_GATEWAY_TARGET 环境变量**，代码不写死 IP；前端 baseURL 用相对路径 /api/v1。
11. **VM 跑测试前先停常驻服务**（8083 管理端口冲突会导致上下文测试失败）：跑 mvn 门禁前 kill user/gateway，跑完 start-dev.sh 拉回。
12. **Windows 下 curl 发中文 JSON 会坏**（编码），联调测试用浏览器或 python；bash 写脚本注意 ${} 转义；e2e 裸 wait 会等 java 服务（用轮询）。
